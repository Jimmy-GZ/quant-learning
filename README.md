# 量化学习

A股双均线（MA5/MA20）金叉死叉策略的可视化与回测脚本。

## 依赖

```
pip install akshare tushare pandas mplfinance matplotlib
```

## 文件说明

| 文件 | 功能 |
|------|------|
| `ma_plot.py` | 下载个股日线数据，绘制 K 线图 + MA5/MA20 均线 + 成交量，并标记金叉/死叉信号 |
| `backtest.py` | MA5/MA20 金叉死叉策略回测（含手续费、滑点、半仓、8% 止损、RSI 过滤、量能共振），对比无过滤/量能共振/RSI<50/RSI<45，输出每笔交易明细及交易次数、胜率、最大回撤、20 日年化波动率 |
| `ma_plot_tushare.py` | 同 `ma_plot.py`，但使用 Tushare 作为数据源 |
| `backtest_tushare.py` | 同 `backtest.py`，但使用 Tushare 作为数据源 |

## ma_plot.py — K 线图绘制

```bash
python ma_plot.py [股票代码]
```

- 股票代码默认为 `000100`（TCL 科技）
- 数据来源：akshare（东方财富），前复权，近 1 年日线
- 输出文件：
  - `output/ma_plot_{代码}.png` — K 线图（红涨绿跌，含 MA5/MA20、成交量副图）
  - `output/ma_plot_{代码}.csv` — 日期、收盘价、MA5、MA20

示例：

```bash
python ma_plot.py 600519
```

## backtest.py — 金叉死叉回测

```bash
python backtest.py [股票代码]
```

### 策略规则

- 初始资金：100,000 元
- 手续费：万 2.5（0.025%，买卖双向收取）
- 滑点：0.1%（买卖双向收取，买入价上浮、卖出价下浮）
- 仓位管理：每次买入只用 50% 可用现金（半仓），剩余资金留作缓冲
- 止损：买入后若收盘价相对买入价下跌 8%，触发止损，下一交易日开盘卖出
- RSI 过滤：计算 RSI(14)，买入条件为 金叉 且 RSI < 阈值（可选 45 或 50），用于过滤假信号
- 量能共振：计算 20 日成交量均值，买入条件为 金叉 且 金叉当日成交量 > 20 日均量 × 1.5（放量确认），量能标记同样顺延至 T+1 执行日，避免未来函数
- 信号：MA5 上穿 MA20 为金叉（买入），MA5 下穿 MA20 为死叉（卖出），基于当日收盘价计算
- 执行：T 日收盘后生成信号，T+1 日开盘价执行（避免未来函数；若数据无 open 列则回退为收盘价）
- 卖出优先级：止损 > 死叉
- 每日持仓净值按收盘价估值

### 数据获取逻辑

1. 优先通过 akshare 获取最新数据，成功后保存到 `output/ma_plot_{代码}.csv`
2. 若获取失败（如接口限流），自动回退到本地已有的 CSV 文件

### 输出

- 数据加载后打印一次 **标的 20 日年化波动率**（基于收盘价，与策略/过滤无关，四组场景共用）
- 同时运行四组场景：无过滤、量能共振、RSI < 50、RSI < 45
- 每个场景打印交易明细表：买入日期、买入价、买入时 RSI、买入时量比、卖出日期、卖出价、卖出原因（死叉/止损）、盈亏
- 对比汇总表：交易次数、胜率、最大回撤、总收益率、最终净值
- 20 日年化波动率：标的收盘价日收益率的 20 日滚动标准差，年化（×√252），取整个回测期间的均值
- 量比：买入执行日前一交易日（金叉当日）成交量 / 20 日均量；若本地数据缺少 volume 列，量能共振场景将无交易且量比显示 `-`

## 输出目录

`output/` 下生成的文件（已加入 `.gitignore`）：

- `ma_plot_{代码}.png` — K 线图
- `ma_plot_{代码}.csv` — 行情数据（date, open, close, MA5, MA20）
