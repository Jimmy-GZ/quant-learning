# 量化学习

A股双均线（MA5/MA20）金叉死叉策略的可视化与回测脚本。

## 依赖

```
pip install akshare tushare pandas mplfinance matplotlib
```

## 文件说明

| 文件 | 功能 |
|------|------|
| `ma_plot.py` | 下载个股日线数据，绘制 K 线图 + MA5/MA20 均线 + 成交量，并标记金叉/死叉信号 |
| `backtest.py` | MA5/MA20 金叉死叉策略回测（含手续费、滑点、半仓、8% 止损、量能共振），对比无过滤/量能共振两组场景，输出每笔交易明细（含买入时 RSI 参考值）及交易次数、胜率、最大回撤、20 日年化波动率 |
| `ma_plot_tushare.py` | 同 `ma_plot.py`，但使用 Tushare 作为数据源 |
| `backtest_tushare.py` | 同 `backtest.py`，但使用 Tushare 作为数据源 |
| `backtest_batch.py` | 批量回测：从沪深300成分股随机抽样 30 只，逐只跑两组场景，汇总整体胜率、平均收益、交易总次数，明细落盘 `output/batch_hs300_detail.csv` |

## ma_plot.py — K 线图绘制

```bash
python ma_plot.py [股票代码]
```

- 股票代码默认为 `000100`（TCL 科技）
- 数据来源：akshare（东方财富），前复权，近 1 年日线
- 输出文件：
  - `output/ma_plot_{代码}.png` — K 线图（红涨绿跌，含 MA5/MA20、成交量副图）
  - `output/ma_plot_{代码}.csv` — 日期、收盘价、MA5、MA20

示例：

```bash
python ma_plot.py 600519
```

## backtest.py — 金叉死叉回测

```bash
python backtest.py [股票代码]
```

### 策略规则

- 初始资金：100,000 元
- 手续费：万 2.5（0.025%，买卖双向收取）
- 滑点：0.1%（买卖双向收取，买入价上浮、卖出价下浮）
- 仓位管理：每次买入只用 50% 可用现金（半仓），剩余资金留作缓冲
- 止损：买入后若收盘价相对买入价下跌 8%，触发止损，下一交易日开盘卖出
- RSI 参考：计算 RSI(14)，仅在交易明细中打印买入时的 RSI 值供参考，不参与买入过滤
- 量能共振：计算 20 日成交量均值，买入条件为 金叉 且 金叉当日成交量 > 20 日均量 × 1.5（放量确认），量能标记同样顺延至 T+1 执行日，避免未来函数
- 信号：MA5 上穿 MA20 为金叉（买入），MA5 下穿 MA20 为死叉（卖出），基于当日收盘价计算
- 执行：T 日收盘后生成信号，T+1 日开盘价执行（避免未来函数；若数据无 open 列则回退为收盘价）
- 卖出优先级：止损 > 死叉
- 每日持仓净值按收盘价估值

### 数据获取逻辑

- 回测周期：近 3 年日线（前复权）
1. 优先通过 akshare 获取最新数据，成功后保存到 `output/ma_plot_{代码}.csv`
2. 若获取失败（如接口限流），自动回退到本地已有的 CSV 文件

### 输出

- 数据加载后打印一次 **标的 20 日年化波动率**（基于收盘价，与策略/过滤无关，两组场景共用）
- 同时运行两组场景：无过滤、量能共振
- 每个场景打印交易明细表：买入日期、买入价、买入时 RSI、买入时量比、卖出日期、卖出价、卖出原因（死叉/止损）、盈亏
- 对比汇总表：交易次数、胜率、最大回撤、总收益率、最终净值
- 20 日年化波动率：标的收盘价日收益率的 20 日滚动标准差，年化（×√252），取整个回测期间的均值
- 量比：买入执行日前一交易日（金叉当日）成交量 / 20 日均量；若本地数据缺少 volume 列，量能共振场景将无交易且量比显示 `-`

## backtest_batch.py — 沪深300批量回测

```bash
python backtest_batch.py
```

- 从沪深300最新成分股中随机抽样 30 只（seed=42，可复现），逐只复用 `backtest_tushare.py` 的回测逻辑跑两组场景
- 单只股票异常（如数据缺失）会跳过并打印，不影响整体
- 明细落盘：`output/batch_hs300_detail.csv`（每只每场景一行，字段：code/scenario/trade_count/closed/wins/total_return/max_drawdown）
- 终端打印：各场景的股票数、交易总次数、整体胜率、平均收益率、盈利股票数、平均最大回撤，以及各股票分场景收益率透视表

### 3 年周期回测结论（30 只沪深300，每只独立 10 万初始资金）

| 场景 | 股票数 | 交易总次数 | 整体胜率 | 平均收益率 | 盈利股票数 | 平均最大回撤 |
|------|-------:|----------:|---------:|----------:|----------:|------------:|
| 无过滤 | 30 | 1236 | 34.0% | +11.46% | 18 | -19.10% |
| 量能共振 | 30 | 254 | 43.5% | +5.69% | 20 | -9.03% |

- 1 年周期样本太短（无过滤/量能共振收益均接近 0），拉长到 3 年后样本量充足（无过滤 1236 笔 vs 1 年 328 笔），结论更稳健
- 量能共振：交易次数降 80%，胜率 34.0% → 43.5%，平均最大回撤 -19.10% → -9.03%（砍半），盈利股票数 18 → 20；代价是牺牲部分大牛股收益，换取回撤可控、胜率更高的实盘体验
- RSI 过滤在历史回测中被验证为反向指标（胜率 15–16%、收益为负），已从回测脚本移除；交易明细仍打印买入时 RSI 供参考
